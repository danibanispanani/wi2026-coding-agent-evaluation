# Team profile images

Upload the four author portraits into this folder using exactly these filenames:

- `chris.jpg`
- `luca.jpg`
- `daniel.jpg`
- `richard.jpg`

Recommended source image:
- square crop or portrait photo
- at least 400 × 400 px
- JPG
- face centered with a little margin around the head

The website automatically loads these files in the Research Team cards. If one image is missing, the initials remain visible as a fallback.
